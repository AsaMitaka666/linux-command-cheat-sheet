# Linux Quick Reference

A quick reference guide for commonly used Linux commands.

---

# Navigation

| Command | Description |
|---|---|
| pwd | Show current directory |
| ls | List files |
| cd | Change directory |
| tree | Show directory tree |
| clear | Clear terminal |

---

# Files

| Command | Description |
|---|---|
| touch | Create file |
| cat | Display file content |
| nano | Edit file |
| cp | Copy files |
| mv | Move or rename files |
| rm | Remove files |

---

# Directories

| Command | Description |
|---|---|
| mkdir | Create directory |
| rmdir | Remove empty directory |
| du | Check disk usage |
| df | Check disk space |

---

# Processes

| Command | Description |
|---|---|
| ps | Show processes |
| top | Process monitor |
| htop | Interactive process viewer |
| kill | Stop process |
| systemctl | Manage services |

---

# Users

| Command | Description |
|---|---|
| whoami | Current user |
| id | User information |
| passwd | Change password |
| useradd | Create user |
| userdel | Delete user |

---

# Networking

| Command | Description |
|---|---|
| ip | Network information |
| ping | Test connection |
| ss | View connections |
| ssh | Remote connection |
| curl | Transfer data |

---

# Security

| Command | Description |
|---|---|
| chmod | Change permissions |
| chown | Change ownership |
| ufw | Firewall management |
| sudo | Run as administrator |

---

# System Information

| Command | Description |
|---|---|
| uname -a | Kernel information |
| uptime | System uptime |
| free -h | Memory usage |
| df -h | Disk usage |
