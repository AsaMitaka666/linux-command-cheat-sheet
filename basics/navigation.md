# Linux Navigation Commands

Linux terminal navigation helps users move between directories and understand their current location.

---

# pwd

## Description

pwd means Print Working Directory.

It shows the current directory path.

## Example

pwd

---

# ls

## Description

ls lists files and directories.

## Example

ls

---

# cd

## Description

cd means Change Directory.

It is used to move between directories.

## Example

cd Documents

---

# Practice

1. Use pwd.
2. Use ls.
3. Use cd.
