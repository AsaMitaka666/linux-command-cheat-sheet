# Linux File Commands

Linux provides many commands for creating, viewing, copying, moving and deleting files.

---

# touch

## Description

`touch` creates a new empty file.

## Syntax

```bash
touch filename
```

## Example

```bash
touch notes.txt
```

---

# cat

## Description

`cat` displays the content of a file.

## Syntax

```bash
cat filename
```

## Example

```bash
cat notes.txt
```

---

# nano

## Description

`nano` is a simple terminal text editor.

## Syntax

```bash
nano filename
```

## Example

```bash
nano notes.txt
```

---

# cp

## Description

`cp` copies files and directories.

## Syntax

```bash
cp source destination
```

## Example

```bash
cp file.txt backup.txt
```

---

# mv

## Description

`mv` moves or renames files.

## Syntax

```bash
mv source destination
```

## Example

```bash
mv old.txt new.txt
```

---

# rm

## Description

`rm` removes files.

## Syntax

```bash
rm filename
```

## Example

```bash
rm unwanted.txt
```
