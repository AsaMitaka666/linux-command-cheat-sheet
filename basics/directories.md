# Linux Directory Commands

Directories are used to organize files in the Linux filesystem.

---

# mkdir

## Description

`mkdir` creates a new directory.

## Syntax

```bash
mkdir directory_name
```

## Example

```bash
mkdir projects
```

---

# rmdir

## Description

`rmdir` removes empty directories.

## Syntax

```bash
rmdir directory_name
```

## Example

```bash
rmdir old_folder
```

---

# tree

## Description

`tree` displays directories and files in a tree-like structure.

## Syntax

```bash
tree
```

## Example

```bash
tree Documents
```

---

# du

## Description

`du` shows disk usage of files and directories.

## Syntax

```bash
du directory
```

## Example

```bash
du -h Downloads
```

---

# df

## Description

`df` shows available and used disk space.

## Syntax

```bash
df
```

## Example

```bash
df -h
```
